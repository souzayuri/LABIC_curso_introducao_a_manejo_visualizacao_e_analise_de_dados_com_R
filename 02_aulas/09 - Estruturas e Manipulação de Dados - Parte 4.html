Visualização de dados

ggplot2

  • Pacote para criação de gráficos no R

  • Baseado na Gramática de Gráficos (Grammar of Graphics)

  • Constrói gráficos em camadas

  • Parte do tidyverse, funciona perfeitamente com o %>%

  • Altamente customizável e com aparência profissional

Visualização de dados

Gramática de Gráficos

Estrutura em camadas

  1. Dados (data): o dataset a ser visualizado

  2. Estética (aes): mapeamento de variáveis para elementos visuais (x, y, cor, forma)

  3. Geometria (geom): tipo de gráfico (pontos, linhas, barras)

  4. Facetas (facet): dividir em painéis

  5. Temas (theme): aparência geral do gráfico

  • Cada camada é adicionada com o operador +

Visualização de dados

Estrutura básica

ggplot(data = dados, mapping = aes(x = variavel_x, y = variavel_y)) +
  geom_point()

  • ggplot(): cria a base do gráfico

  • aes(): define o mapeamento estético (quais variáveis usar)

  • geom_*(): define a geometria (tipo de gráfico)

  • Camadas são unidas com + (não %>%)

Barras de erro

geom_errorbar()

Média e desvio padrão

dados %>% 
  group_by(Treatment) %>% 
  summarise(
    mean = mean(Richness),
    sd = sd(Richness)
  ) %>% 
  ggplot(aes(x = Treatment, y = mean)) +
  geom_col(fill = "steelblue") +
  geom_errorbar(aes(ymin = mean - sd,
                    ymax = mean + sd),
                width = 0.2)

Exportar gráficos

  geom_point() +

       width = 8, 
       height = 6,

  • Formatos: .png, .pdf, .jpg, .svg

Pipeline completo

Exemplo integrado

dados %>% 
  # Processar dados
  filter(!is.na(Richness)) %>% 
  group_by(Treatment, Location) %>% 
  summarise(
    Richness_mean = mean(Richness),
    Richness_sd = sd(Richness)
  ) %>% 
  # Criar gráfico
  ggplot(aes(x = Location, 
             y = Richness_mean,
             fill = Treatment)) +
  geom_col(position = "dodge") +
  geom_errorbar(
    aes(ymin = Richness_mean - Richness_sd,
        ymax = Richness_mean + Richness_sd),
    position = position_dodge(0.9),
    width = 0.2
  ) +
  scale_fill_brewer(palette = "Set2") +
  labs(
    title = "Riqueza média por localidade",
    x = "Localidade",
    y = "Riqueza média",
    fill = "Tratamento"
  ) +
  theme_minimal() +
  theme(legend.position = "top")
