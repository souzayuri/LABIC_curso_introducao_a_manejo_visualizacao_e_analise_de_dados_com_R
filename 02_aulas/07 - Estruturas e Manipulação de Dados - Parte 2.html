Importação e exportação de dados

Formatos mais comuns são arquivos: .txt e .csv

Abrindo .txt

  • Precisa definir como os dados estão separados = sep = "\t"
  • Precisa definir que quer mostrar o cabeçalho das colunas = header = TRUE
# indicar o caminho, usem a tecla tab 
# e o R ira listar tudo que existe no diretório
dados.txt <- read.table("../01_dados/biota_diversidade.txt", 
                    sep = "\t",
                    header = TRUE)

dim(dados.txt) # mostra número de linhas e de colunas
[1] 172  18
