Pacotes

  • O R apresenta pacotes, que são um conjunto de funções.

  • Existem pacotes para diversos tipos de funcionalidades e uso

  • A função do pacote é providenciar um conjunto de funções, assim você não precisa escrever elas.

  • Dentre esses pacotes o mais famoso é o tidyverse:

    • um pacote com a função de instalar e carregar outros pacotes

    • pacotes para manipulação de dados, voltado para Ciência de Dados

    • É considerado um “universo” à parte do R, pois todas as suas ferramentas possuem formas de uso consistentes e funcionam muito bem em conjunto

if_else()

Condicional simples

dados %>% 
  mutate(
    riqueza_cat = if_else(riqueza > 10, 
                          "alta", 
                          "baixa")
  )
  • Se condição for verdadeira, retorna primeiro valor
  • Senão, retorna segundo valor

case_when()

Múltiplas condições

dados %>% 
  mutate(
    riqueza_cat = case_when(

      riqueza > 10 ~ "alta",
      riqueza > 5 ~ "média",

    )
  )
  • Formato: condição ~ resultado
  • Avalia condições em ordem

Junção de Tabelas

left_join()

Manter todas as linhas da tabela da esquerda

dados %>% 
  left_join(traits, by = "Familia")
  • Mantém todas as linhas de dados
  • Adiciona colunas de traits quando há match
  • NA quando não há correspondência

Junção de Tabelas

right_join()

Manter todas as linhas da tabela da direita

dados %>% 
  right_join(traits, by = "Familia")
  • Mantém todas as linhas de traits
  • Adiciona colunas de dados quando há match

inner_join()

Manter apenas linhas com match em ambas

dados %>% 
  inner_join(traits, by = "Familia")
  • Mantém apenas linhas que têm correspondência em ambas tabelas
  • Remove linhas sem match

full_join()

Manter todas as linhas de ambas as tabelas

dados %>% 
  full_join(traits, by = "Familia")
  • Mantém todas as linhas de ambas tabelas
  • NA onde não há correspondência

semi_join()

Filtrar baseado em outra tabela

dados %>% 
  semi_join(traits, by = "Familia")
  • Mantém linhas de dados que têm match em traits
  • Não adiciona colunas de traits
  • Útil para filtrar dados

anti_join()

Filtrar excluindo matches

dados %>% 
  anti_join(traits, by = "Familia")
  • Mantém linhas de dados que NÃO têm match em traits
  • Não adiciona colunas de traits
  • Útil para identificar diferenças

Pipeline completo

Exemplo integrado

resultado <- dados %>% 
  # 1. Filtrar dados
  filter(Bioma == "Mata Atlântica") %>% 
  # 2. Selecionar colunas
  select(Ordem, Familia, riqueza) %>% 
  # 3. Criar nova coluna
  mutate(riqueza_cat = case_when(
    riqueza > 10 ~ "alta",
    riqueza > 5 ~ "média",
    TRUE ~ "baixa"
  )) %>% 
  # 4. Agrupar e resumir
  group_by(Ordem, riqueza_cat) %>% 
  summarise(
    n_familias = n(),
    riqueza_total = sum(riqueza)
  ) %>% 
  # 5. Ordenar
  arrange(desc(riqueza_total))

# 6. Exportar
write_csv(resultado, "../01_dados/resultado.csv")
